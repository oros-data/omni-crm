# AGENTS.md

## Code style
- Comments are limited to docstrings and TODOs; docstrings are encouraged.
- Write functional Python: plain functions and pure helpers.
- Use dataclasses or similar constructs only to categorize data.
- Never repeat yourself; extract a shared helper the second time a pattern appears.

## Schema
- Primary keys are UUIDs generated by Postgres `uuidv7()`; never serial or identity integers.
- `created_at` and `updated_at` are always set by the database clock through the `set_updated_at()` trigger, never by the application or from a CRM timestamp; every migration adding `updated_at` also adds that trigger.

## Migrations
- Tables and columns come from `models.py` via autogenerate; add by hand in the revision only what autogenerate cannot express, such as the `updated_at` trigger.
- Generate revisions with `alembic revision --autogenerate`.
- Apply with `alembic upgrade head` on the local Postgres.
- Confirm `alembic check` reports no new operations.
